# 전체·공종별 라이브 TBM 동시 방송 (2026-10-21)

## 범위와 계약

- 현장 공통(`trade_types=[]`) 1개 + 겹치지 않는 공종 채널들의 동시 라이브를 허용한다. 여러 공종을 선택하면 각 공종을 점유한다. 공통은 ‘전국’ 권한과 다른 개념이다.
- TBM 작성의 전체는 공통 단독 선택, 근로자의 오늘 공종 전체는 기존 select-all16 유지. 20개 언어 공종명과 공통 표기를 재사용한다.
- 기존 일반 텍스트 전파는 횟수 제한 없음. 같은 현장의 별도 일반 라이브 통역(non-tbm 세션)은 기존 수신 UI 호환을 위해 다른 활성 라이브와 겹치지 않게 차단한다.
- 새로운 방송이 다른 방송을 종료하지 않는다. 현장 권한은 SiteGuard, 제어는 발신자 ID로 검증한다. TEMP_WORKER의 전파/서명 권한을 확대하지 않는다.

## 구현

- V045: V028의 활성 현장 unique index 제거, channel-overlap trigger 추가. 앱 시작 트랜잭션과 DB trigger에서 같은 advisory lock(737037)을 사용해 동시 시작을 직렬화한다. 기존 행/과거 서명/공종 배열은 변경하지 않는다.
- `/live/sessions`는 전체 활성 목록 `sessions`를 반환하고 `sessionId` 지정 시 정확히 필터한다. 호환 `session`은 1개일 때만 반환한다. 여러 방송 중 최신 하나를 임의로 반환하지 않는다.
- 홈은 공통 + 오늘 공종 교집합을 표시한다. 링크에 `broadcastSession`을 넣어 선택을 고정한다. receiver의 음성·초안·요약·참여 조회는 exact session ID를 유지하며 다른 SSE를 무시한다. 동시에 두 음성을 재생하지 않는다.
- 전국 시작은 모든 대상 현장 충돌을 먼저 검사하고 하나라도 충돌하면 전체 롤백한다. 전국 종료는 해당 그룹 하위 세션만 종료한다.

## 검증

- PostgreSQL `NationwideTbmDatabaseTest`: 공통/로프공/철근 동시 3개, 중복 공통/복수 공종 겹침 거절, 소유자/타현장 권한, 같은 ID 재시도, 동시 경쟁 시작 1개만 성공, 직접 SQL trigger 차단, 전국 공통+현장 공종, 전국 충돌 원자성, 정확한 세션 참여/다른 요약의 서명 권한 미부여.
- 전체 Gradle 테스트 197건 중 195건 성공, 외부 DeepL 실제 호출 2건은 키 없이 제외. 로컬 Docker는 `JAVA_TOOL_OPTIONS=-Dapi.version=1.44`로 Testcontainers API 호환을 맞춰 실행했다.
- TypeScript 및 변경 공통 컴포넌트 ESLint, 라이브 전파/공종/알림/오늘 공종 단위 검사 통과.
- `tbm-trade-selector-browser.mjs`: 320px, 20개 언어, 근로자·관리자 작성 공통 선택 payload=[], 오늘 공종 전체 선택 payload=16개.
- `tbm-live-handoff-browser.mjs`: 모의 API 기반 실제 Next/BFF/Chrome에서 공통+선택 공종 표시, 비선택 공종 제외, 다중 방송 자동 선택 없음, 정확한 링크 선택, 타 방송 SSE/초안/종료 무시, 다른 방송이 계속 켜진 동안 선택 방송 요약/서명 전환. 기존 번역 실패 재시도·미참여자 완청 규칙도 검증.
- 실제 현장 마이크/모바일 OS 푸시/외부 번역 공급자의 지연·음질은 이번 모의 시험으로 검증한 것이 아니다. 운영에 테스트 TBM을 발송하지 않는다.

## 배포 및 롤백

- 배포 전 활성 방송 수와 backup service 성공 확인. 프론트·백엔드·V045를 같은 immutable release로 배포한다.
- 새 동시 세션이 존재하는 상태에서 구버전 앱으로 단순 롤백하면 구버전의 현장 전체 종료 동작이 발생할 수 있다. 먼저 발신자와 협의해 활성 세션을 정상 종료하고, 동일 현장 중복 활성 행이 없는지 확인한 다음 롤백한다. 자동으로 사용자 방송을 종료하거나 서명 데이터를 삭제하지 않는다.
- V045 및 신규 데이터를 롤백 목적으로 삭제하지 않는다. 기존 index를 복원하려면 활성 중복 검사를 선행하는 별도 검토 migration이 필요하다.
