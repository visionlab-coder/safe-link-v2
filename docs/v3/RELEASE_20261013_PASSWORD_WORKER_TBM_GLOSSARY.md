# 2026-10-13 승인 변경 배포

## 범위

- 관리자 가입·초대·비밀번호 복구·최초 관리자 생성 최소 길이 10자. BCrypt cost 12 유지.
- 관리자 가입 화면에 길이 안내 상시 표시, 이름 확인·필수 입력·불일치 등 비활성 사유 표시. 기존 로그인은 길이 제한 추가하지 않음.
- 정식 WORKER의 `/worker/tbm/create` 및 소속 현장 TBM 작성·라이브·전파 허용. TEMP_WORKER, VIEWER는 전파 불가. 관리자 화면/사용자 관리/전국 전파 권한은 부여하지 않음.
- 현장용어집 검색: 현장어·표준어·카테고리 부분 일치, 공백으로 나눈 검색어 모두 일치, 대소문자/유니코드 정규화, 결과 수·초기화·빈 결과. 전체 사전을 한 번 받은 뒤 화면에서 필터링하므로 새 DB/API 변경은 불필요. 내보내기는 기존대로 전체 목록.
- 모바일 1:1 채팅 소음 감지 버튼을 입력창 위에 배치하여 전송 버튼과 겹치지 않게 함.
- 보류 중인 직원 분류/관리자 역할 개편 및 V038/V039 마이그레이션은 이번 배포에서 제외. 기존 소스 변경은 로컬에 보존.

## 선반영한 운영 데이터

- 요청한 관리자 2개 계정의 비밀번호 변경 및 로그인/시험 세션 로그아웃 확인 완료. 비밀번호/해시는 문서·코드·로그에 기재하지 않음. 권한과 현장 연결은 변경하지 않음.
- 제공 용어집은 기존 280개를 보존하고 218개 추가(총 498개). 200개 활성, 동음이의어 18개 비활성. 신규 119개만 단일 의미 자동 변환 가능, 81개 다의어는 변환 보류. 총 99개는 무조건 자동 치환하지 않음.
- 재실행 가능한 add-only SQL 및 원본 파일 해시를 `scripts/import-glossary-additions-20261013.sql`, `scripts/data/glossary-additions-20261013.json`에 보존. 운영 반영 전 서버 제한권한 백업 저장. 배포 과정에서 재수입하지 않음.
