# TBM 위험성 평가 목록 — 2026-10-06

## 사용자 요청과 범위

- 첨부 `최초 위험성평가 (서원토건).xlsx`의 위험성 평가 목록을 관리자 TBM 작성 화면에 추가.
- 기존 기초교육 라이브러리 위치를 활용. 기본 자료는 첨부 파일, 기존 예시 5개는 자료 선택의 `기본 예시`로 보존.
- 사용자 후속 요청에 따라 상단 공종 카테고리 버튼을 복원하고 페이지 구분 제거. 버튼을 누르면 해당 공종 전체 항목 표시(이전 검색/세부공종/중점 필터 초기화). 세부공종·중점관리 필터와 수동 검색은 유지하며 카테고리를 바꿔도 선택 항목 유지. 현재 필터 항목 전체 선택/해제 제공.
- 첨부한 기존 디자인에 맞춰 제목→카테고리→중점관리/전체 선택→카드 순서를 유지하고 밝은 회색 배경/흰색 카드로 변경. 카드 배지는 재해유형→위험등급→중점→공종 순서. 자료·검색·세부공종은 접이식 보조 영역에 유지하며 선택 시에만 삽입 하단바 표시. 실제 원본 9개 공종과 기본 예시 5개 카테고리를 임의로 재분류하지 않음.
- 선택한 위험요인·관리계획을 한국어 초안 끝에 추가. 기존 본문을 덮어쓰지 않으며 번역·전파는 기존 TBM 절차 사용.
- 음성 키워드 자동 감지/자동 삽입/자동 전파, 위험등급 재평가, 특정 현장의 법적 평가 확정, 근로자 표시 흐름 변경은 포함하지 않음.

## 원본 대조

- 시트: `신정스카이하임 최초위험성평가(서원토건)`, 범위 `A11:I461`.
- 451개 항목 / 9개 공종 / 원본 `●` 중점관리 142개. 빈도·강도·등급은 계산하거나 반전하지 않고 원본 숫자 보존.
- 병합된 대공종은 실제 병합 범위의 첫 셀로 복원. 위험요인·관리계획은 앞뒤 공백만 제거하고 원문 유지. 행 번호, 원본 파일 SHA-256, 중점관리 원시값 보존.
- 원본 등급 2는 144개이나 `●`는 142개임. 표 상단 설명만으로 임의 보정하지 않았으며 중점관리 필터는 실제 표시를 기준으로 함. I369의 숫자 0도 중점으로 해석하지 않음.
- 추출기: `scripts/extract-risk-assessment.py`. XLSX 읽기 전용, stdout JSON만 출력. 원본 파일을 수정하지 않음.

## 구현과 권한

- Spring `TbmLibraryController`, `backend/src/main/resources/tbm/*.json`이 버전 관리되는 참조 목록을 제공. 운영 DB에 임의 삽입하거나 기존 라이브러리 테이블을 덮어쓰지 않음.
- `GET /api/v1/tbm/library`: ROOT/HQ_ADMIN/SITE_ADMIN/SAFETY_MANAGER만 허용. 비로그인/WORKER/TEMP_WORKER/VIEWER 차단. 이 목록은 공유 참조자료이며 현장별 실적/서명/대화 데이터가 아님.
- Next `/api/tbm/library`는 세션 전달 프록시. 프론트에 별도 샘플 fallback으로 서버 장애를 숨기지 않음.
- `SafetyLibraryModal`은 흰색 카드, 명확한 위험요인/관리계획 구분, 검색·필터·선택 유지, 오류/재시도, 요청 취소, 키보드 닫기·포커스 이동 제공.
- 라이브 최종 처리 중에는 삽입을 막는 기존 보호 유지. 아직 운영 배포하지 않았으며 프론트·백엔드 동시 배포 필요. 신규 DB migration 없음.
