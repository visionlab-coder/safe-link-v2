## 1. 오류 단계와 원인

| 증상 | 확인된 사실 |
| --- | --- |
| 들어가도 → 들어모서리 / 시작합시다 → 시작합보조원 | 한국어 치환 함수, STT 후처리, 번역 전처리는 한 글자만 경계를 보호하고 두 글자 이상은 부분 문자열도 치환했다. 운영 사전의 가도→모서리, 시다→보조원과 기준 소스로 두 오류를 재현했다. |
| 가타와꾸 → 가타테두리 | 복합어가 없는 사전에서 와꾸→테두리가 내부에 일치하면 재현된다. 현재 운영 사전에는 가타와꾸가 있다. 당시 사전·캐시·인식 원문은 없으므로 당시 누락 경위는 확정하지 않았다. 브라우저 사전 캐시에 만료가 없었던 점도 확인했다. |
| 함마 미변환 | 운영 값은 해머(망치). STT·번역 전처리가 괄호 포함 항목을 통째로 제외했다. |
| 사포도 미변환 | 현재 운영 값은 서포트, 동바리. 등록은 확인했으나 당시 미변환 원인은 당시 인식 원문과 사전 상태 없이는 확정할 수 없다. 이번 시험에서 지정한 뜻인 동바리를 전달 용어로 반영했다. |
| 여러 뜻·의무 착용 삽입 | 사전의 해체, 뜯기 / 보조공, 조수 / 안전 헬멧(의무 착용)을 통째로 삽입하는 경로가 있었다. STT의 괄호 제외와 브라우저의 전체 삽입 규칙도 달랐다. |

## 2. 조치

- 브라우저/TBM 초안·STT 후처리·번역 전처리를 `korean-glossary.ts`로 통일했다. 모든 길이의 용어에서 앞 경계와 뒤 조사·허용 어미를 검사한다.
- 원문을 한 번 스캔하여 가장 긴 온전한 용어만 바꾼다. 다른 단어 내부·미등록 복합어 내부를 훼손하지 않고, 변환 결과의 재치환/설명 확장을 차단한다.
- 가타와꾸/가다와꾸→거푸집, 사포도→동바리, 함마→망치, 바라시→해체, 데모도→보조공으로 지정했다. **시험에서 명시한 표기와 의미만 적용**했으며 유사 발음을 추측하여 추가하지 않았다.
- 가도·시다·가리·가다 등 일반어와 충돌하는 항목과 미검토 다의어는 원문을 유지한다. 문맥 검토 없이 첫 번째 뜻을 임의 선택하지 않는다. 모든 다의어가 자동 해결된 것은 아니다.
- 사전 설명은 `standard`에 참고용으로 유지한다. Spring API에 `delivery_term`, `delivery_policy_version`을 추가했으며 프론트·백엔드는 같은 JSON 정책을 사용한다. 운영 사전 설명을 삭제하지 않았다.
- 변환 및 한국어 번역 결과에 붙던 규칙식 존댓말 재작성을 제거했다. 금지·부정·조건·질문을 다시 쓰지 않는다. 치환으로 받침이 달라지는 기본 조사는 맞춘다.
- 번역 프롬프트에 금지·부정·조건·수량 보존과 미발언 내용 추가 금지를 명시했다. 선택형 로컬 번역 경로에서도 불확실한 용어를 문장 앞에 강제 삽입하지 않는다. 프롬프트만으로 외국어 정확도를 보장하지 않는다.
- STT의 추측성 안 미터→안전 보정은 제거하고 인식 원문을 별도 응답한다. 브라우저 사전 캐시는 60초 갱신으로 변경했다.
- 배포 전 회귀시험에 이번 한국어 변환/API/라이브 시험을 추가했다. 배포 워크플로를 실행한 것은 아니다.

## 5. 실제 음성 재시험과 한계

- STT 응답: `originalTranscript`는 공급자의 인식 원문, `normalizedTranscript`/`transcript`는 용어 변환문, `changes`는 적용 용어, `glossaryPolicyVersion`은 정책 버전이다.
- 번역 응답: `originalText`는 해당 요청 입력, `normalizedText`는 번역에 사용한 문장, `glossaryChanges`는 추가 치환, `translated`는 최종 번역 응답이다. 번역의 originalText를 음성인식 원문으로 오해하지 않도록 앞 STT 응답과 대조한다.
- 신규 원음 수집·원문 로그 저장·과거 원문 복원 기능은 추가하지 않았다.
- 실제 녹음·휴대폰 시험은 이번에 수행하지 않았다. 같은 음성을 TBM·라이브·1:1 입력으로 보내 인식 원문 → 용어 변환문 → 최종 번역문을 비교해야 한다.
- 필수 사례: 들어가도 됩니까?, 작업 시작합시다, 가타와꾸를 해체하지 마세요, 사포도가 없으면 들어가지 마세요, 하이바를 쓰지 않으면 들어갈 수 없습니다.
- 인식 원문이 잠/짠/사포토 등으로 나오면 별도 STT 사례로 기록한다. 불확실한 발음을 의미 추측으로 치환하지 않는다.
- 외국어 통역 정확도, 소음·발음 편차, 문맥상 다의어는 별도 검수 대상이다. 수정본 재시험 후 현장 적용 여부를 판단해야 한다.
