## TBM 관리자 질문 연결 — 2026-09-30

- 사용자 확정 방식: TBM 화면의 ‘관리자에게 질문하기’ → 기존 `/worker/chat`에서 해당 관리자 자동 선택. TBM 내부에 별도 채팅 시스템을 만들지 않는다.
- 최종 TBM은 서버 DB `created_by`를 조회 응답에 추가해 발송자를 사용한다. 실시간 방송은 현재 세션의 `started_by`를 사용하며 과거 TBM 발송자로 대체하지 않는다.
- 채팅 수신자 선택은 `/api/worker/chat/admins`의 서버 인증/현장 권한으로 허용된 목록 안에서만 한다. 대상이 없으면 다국어 안내, 임의 관리자 선택·메시지 자동 전송 없음. 기존 임시 근로자 제한 유지.
- 질문 버튼·연결 불가 안내·TBM 복귀 링크는 지원하는 20개 언어 제공. 채팅으로 이동하면 TBM 화면은 닫히므로 실시간 음성도 멈춘다. 동시 청취/내장 Q&A는 이번 범위가 아니다.

- 검증 대상: `tests/tbm-chat.cjs`, `TbmControllerTest` 발송자 직렬화/현장 권한, TypeScript, ESLint. 운영 배포는 이번 요청에 포함되지 않음.
