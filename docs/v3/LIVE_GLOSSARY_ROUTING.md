# 라이브 현장 용어집 경로 보완 (2026-09-28)

- 기존 관리자/근로자 라이브의 /api/translate 요청은 useGlossary=true이며 한국어 은어 정규화와 외국어→한국어 전처리를 사용한다.
- 한국어 STT 결과 역시 DB 활성 사전 + 기본 사전으로 정규화한다.
- 누락: Flitto RTT가 반환한 translations는 정규화 전 생성된 값인데 관리자 라이브가 이를 우선 사용하면서 번역 경로를 생략했다.
- 변경: /api/stt에서 live 한국어 발화가 정규화로 변경됐거나 활성 사전의 은어/표준어를 포함하면 RTT 번역을 전달하지 않는다. 기존 라이브 사전 번역 및 근로자 폴백이 용어집을 적용한 원문으로 번역한다.
- 현장 용어 없는 발화는 기존 RTT 번역을 재사용한다. 근로자 외국어 응답은 기존 glossary 번역 경로를 유지한다.
- Google용 speechHints와 STT 공급자 설정은 변경하지 않는다. Flitto 자체 사용자 사전 업로드 기능을 새로 구현한 것은 아니다.
- 재번역이 필요한 발화에는 추가 지연/비용이 있을 수 있다. 용어집은 인식/번역 정확도를 보장하지 않는다.
- 검증: node tests/live-glossary-policy.cjs (8개), tsc, ESLint. 실음성 및 현장 소음 E2E는 별도 필요.
- 로컬 Next API 변경이다. 운영 웹 서버 반영에는 프론트 서버 배포가 필요하다.
