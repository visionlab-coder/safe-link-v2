# 근로자 화면 한국어 병기

## 목표와 적용 범위 (2026-10-23)

- 한국인 관리자가 외국인 근로자의 휴대폰 조작을 도울 수 있도록 선택 언어 뒤에 한국어를 괄호로 병기한다.
- 근로자 로그인/역할 선택, 로그인 후 홈(임시 근로자 포함), 간편가입, 정식 전환, 근로자 TBM 작성·전파 화면에 적용한다.
- TBM 공종 선택/배지, 오늘 공종 선택, 가입 동의·검증 안내, TBM 요약 영역 제목·버튼도 포함한다.
- 한국어 선택 또는 두 문구가 동일한 경우 반복하지 않는다. 관리자 전용 가입/작성 화면은 기존 단일 언어를 유지한다.
- 실제 TBM 원문·요약·용어집 교정 결과·위험성평가 자료·사용자 이름에는 설명을 삽입하지 않는다. 이 변경은 UI 병기이며 자료 자체를 번역하는 기능이 아니다.

## 구현과 경계

- `src/lib/korean-help.ts`는 표시 전용 문자열/메시지 사전 어댑터다. 기존 20개 언어 사전과 한국어 사전을 조합하며 원본 사전을 변경하지 않는다.
- 공유 `EnglishNameField`, `TbmTradeOptions`, `TbmTradeBadges`, `SafetyLibraryModal`은 선택적 `koreanHelp`를 제공하며 기본값은 false다.
- 관리자/근로자 공유 TBM 페이지는 `/worker/` 경로에서만 병기를 켠다. 공종의 서버 저장 값, 전체 방송의 빈 공종 배열, 생년월일·전화번호·현장 ID·홍채 ID 및 권한 규칙은 변경하지 않는다.
- 긴 병기 문구를 위해 근로자 TBM의 헤더/초안 도구 영역은 줄바꿈하고, 좁은 화면의 공종은 한 열로 표시한다.
- V2는 수정하지 않았다. 사용자 승인 범위의 표시 변경만 적용하며 DB 마이그레이션/백엔드 변경은 없다.

## 검증

- `tests/korean-help.test.cjs`: 한국어/동일 문구 중복 방지, 관리자 비활성 범위, 함수형 메시지, 원본 불변 및 20개 언어 가입 사전.
- `tests/worker-korean-help-browser.mjs`: 전용 로컬 서버/모의 API만 사용. 20개 언어 로그인·가입·전환·공종 선택, 작은 화면 폭, 가입·전환·전파 요청 값 보존 및 관리자 단일 언어를 확인한다.
- 가입/공종/TBM 발송/음성 언어/관리자 가입 관련 단위 회귀 테스트 23건 통과.
- 로컬 브라우저 검증 완료: 20개 언어 로그인·가입·전환·TBM(390px), 근로자 홈(320px), 가입 중복 안내, 정식 전환 요청, TBM 원문/공종 요청 값 보존 및 관리자 비적용 통과.
- TypeScript 검사(`npx tsc --noEmit --incremental false`), 변경 소스 ESLint, `git diff --check` 통과. 브라우저 빌드 중 생성 타입 파일 교체로 발생한 일시적 TS6053은 브라우저 종료 후 재검사하여 통과했다.
- 운영 계정 가입·전환·방송은 수행하지 않았다.
