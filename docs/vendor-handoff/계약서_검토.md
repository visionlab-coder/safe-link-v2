## ⚠️ 서명 전 반드시 보완 (CRITICAL)

### 1) 과업 범위가 계약서에 없음 ★최대 구멍
- 제2조②가 **"세부 과업 범위는 별도 협의를 거쳐 확정"** → 무슨 기능을 만드는지 계약서에 **미명시**.
- 제6조③ 검수는 "**당초 계약 범위 내**"만 보완 의무 → 범위가 모호하면 "그건 범위 밖" 으로 빠질 수 있음.
- **조치**: **[별첨1 과업범위 명세]** 를 계약서에 첨부하고, "을은 별첨1의 기능을 모두 구현한다" 명문화. 별첨1 = 우리 **이관 패키지(SAFE-LINK_VENDOR_HANDOFF.md)** 기준 + 아래 필수 기능 열거:
  - 관리자·근로자 로그인 / TBM 브로드캐스팅 / **라이브 통역(실시간 STT→번역→TTS, 다국어)** / 1:1 대화 / TBM 서명 / NFC·QR 스캔·출입 / 16개국어 이상

### 2) 스토어 "출시" 책임 불명확
- 품목명 "**출시용 개발**" — 스토어 **등록·심사 통과까지** 포함인지, 반려 시 무상 수정인지 없음.
- **조치(특약)**: "출시용 개발은 Google Play·App Store **심사 통과·게시까지** 포함하며, 심사 반려 시 무상 수정을 [n]회 제공한다. 개발자 계정·서명 인증서 명의/비용 주체는 [   ]." (웹뷰 래퍼 거부 이력 고려 — 중요)

### 3) 검수 합격 기준이 없음 + 자동 검수완료 주의
- 제6조②: "14영업일 내 이의 없으면 **검수 완료 간주**" → 바쁘면 자동 통과 → 잔금 지급 의무 발생.
- 합격 "기준"이 없어 부실해도 통과될 수 있음.
- **조치(특약)**: "검수 합격은 **안드로이드·iOS 각 실기기에서 별첨1 핵심기능(특히 라이브 통역) 정상 동작** 확인을 기준으로 한다." + 검수기간 기산점을 "**갑이 검수 가능한 빌드 수령일**"로, 필요시 14영업일 연장 가능.

### 4) 개인정보 위수탁(법적 필수) 누락
- 제8조에 "개인정보" 언급뿐. 근로자 PII(전화 등)를 을이 처리 → **개인정보보호법 제26조 위수탁** 별도 요건(안전조치·재위탁 제한·관리감독·손해배상).
- **조치**: **개인정보 처리위탁 조항(또는 별도 위수탁 계약)** 추가. 시크릿은 보안 채널 전달·종료 시 파기 명시.

### 5) IP — 우리 기존 코드 보호 모호 (제9조②)
- 제9조②: 을의 "기존 기술·라이브러리·프레임워크" 권리는 을 귀속, 갑은 "계약목적 범위 내 사용"만.
- 위험: "**기존 솔루션 코드 리뉴얼**" 결과물을 을이 자기 "프레임워크"라 주장하면 갑 소유가 아닌 사용권으로 묶일 수 있음.
- **조치(특약)**: "**SAFE-LINK 기존 코드 및 그 리뉴얼·파생 결과물의 저작권은 갑에게 귀속**하며, 제9조②의 '을 보유 자산'은 SAFE-LINK와 무관한 범용 라이브러리에 한한다. 을은 갑 결과물에 **제3자 라이선스 충돌이 없도록** 하고 사용 OSS 목록을 제출한다."
