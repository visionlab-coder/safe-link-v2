# SAFE-LINK V2 — 미추적 파일 이관 분류

기준일: 2026-06-29
기준 브랜치: `codex/vendor-handoff-p0`
기준 명령: `git -c core.quotepath=false ls-files --others --exclude-standard -z`

## 요약

H-01 조사 시작 시점의 작업 폴더에는 Git에 포함되지 않은 파일 580개가 있었다. 이 파일은 사용자 WIP이므로 본 작업에서 삭제·이동·일괄 커밋하지 않는다. 아래 수치는 H-01 기준선이며 이후 이관 P0에서 새로 만든 검증 파일은 포함하지 않는다.

| 분류 | 파일 수 | 처리 원칙 |
|---|---:|---|
| 후보 제품 소스 | 61 | 별도 기능 검증 후 선택 커밋; 현재 이관 P0에 자동 포함 금지 |
| 후보 검증 도구 | 12 | 재현성·시크릿 사용 여부 검토 후 선택 커밋 |
| 이관/Harness 문서 | 11 | 업체에 필요한 문서만 선택 커밋 |
| 참고 문서 | 10 | 계약·기술 판단에 필요한 것만 별도 참고자료로 전달 |
| 생성물·개인 작업물 | 486 | 기준 소스와 전달 ZIP에서 제외 |
| 합계 | 580 | 작업 폴더 전체 ZIP 금지 |

## 분류 규칙

### 후보 제품 소스

- `apps/mobile/**`: Android PoC와 모바일 참고 구현. 현재 일부만 Git 추적 상태이므로 범소프트웨어 전달 전 별도 clean-build 검토가 필요하다.
- `services/**`: 실험용 M2M100 서비스. 핵심 웹 제품과 분리하고 선택 기능으로 표시한다.
- `supabase/migrations/20260607_*`, `20260622_*`: 운영 DB 적용 여부를 확인하기 전에는 소스 후보이며 운영 적용 금지다.

### 후보 검증 도구

- 미추적 `scripts/**` 12개는 인증·Harness·온디바이스 품질·M2M100·라이브 통역 검증 도구다.
- 로컬 경로, 개인 계정, 운영 키 의존 여부를 검토한 뒤 재현 가능한 스크립트만 전달한다.

### 이관/Harness 문서

- `docs/harness/**`, `docs/vendor-handoff/**` 중 실제 인수에 필요한 문서만 Git에 포함한다.
- 상태 문서에 오래된 브랜치·SHA가 있으면 기준 소스로 사용하지 않고 참고 이력으로 표시한다.

### 참고 문서

- STT/TTS 계획, 특허 적용 가이드, 회의 원문 등은 제품 빌드 입력이 아니다.
- 개인정보·계약정보를 검토한 뒤 필요 시 소스와 분리된 보안 채널로 전달한다.

### 생성물·제외

- `.claude/scheduled_tasks.lock`
- `docs/generated/**`
- `**/__pycache__/**`
- 빌드 산출물, 렌더 이미지, PPTX/PDF/DOCX, 임시 추출물

## 전달 규칙

1. `git archive` 또는 깨끗한 clone의 Git 추적 파일을 기준으로 한다.
2. `node_modules`, `.env*`, `.vercel`, `.wrangler`, `.open-next`, `.next`, Android build 결과를 제외한다.
3. 후보 소스는 각각 빌드·테스트·민감정보 검사를 통과한 커밋으로만 추가한다.
4. 실제 시크릿은 저장소와 분리된 승인된 보안 채널로 전달한다.
5. 전달 commit SHA와 파일 체크섬을 수령 확인서에 기록한다.
