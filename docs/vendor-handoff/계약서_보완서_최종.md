## 2. 추가 특약 (제13조 ~ 제22조)

**제13조 (과업 범위)** ① 제2조 No.3~5의 기능 범위는 **[별첨1 과업범위 명세]** 에 따르며, 을은 별첨1 기능을 모두 구현·인도한다. ② 별첨1과 본문 상충 시 별첨1 우선. ③ 갑 제공 이관 패키지(`SAFE-LINK_VENDOR_HANDOFF`)를 기능 참조자료로 한다.

**제14조 (백엔드 재사용)** ① "코드 리뉴얼"은 **기존 Supabase 백엔드·API 유지·재사용**을 원칙으로 하며, 구조 변경 시 갑의 사전 서면 동의를 받는다.

**제15조 (스토어 출시·심사)** ① "출시용 개발"은 **Google Play·Apple App Store 등록·심사 통과·게시까지 포함**한다. ② 심사 반려 시 무상 수정을 **[3]회**까지 제공한다(갑 귀책 제외). ③ 개발자 계정·서명 인증서 명의/비용 주체는 **[갑/을]**, 권한은 최소 부여.

**제16조 (검수 합격 기준)** ① 검수 합격은 **안드로이드·iOS 각 실기기에서 별첨1 핵심 기능(특히 라이브 통역 실시간 음성→번역→음성) 정상 동작**을 갑이 확인함을 기준으로 한다. ② 제6조②의 검수기간은 **을이 검수 가능한 빌드를 갑에게 인도한 날**부터 기산한다. ③ 핵심 기능 미동작은 불합격으로 보고 을은 계약 범위 내에서 보완한다.

**제17조 (지식재산권 보충)** ① **SAFE-LINK 기존 코드 및 리뉴얼·파생 결과물의 저작권·지식재산권은 갑에 귀속**한다. 제9조②의 "을 보유 자산"은 SAFE-LINK와 무관한 범용 라이브러리에 한한다. ② 을은 제3자 라이선스 충돌이 없도록 하고 **사용 OSS·라이선스 목록을 납품 시 제출**한다.

**제18조 (개인정보 처리 위탁)** ① 을은 근로자 개인정보 처리 수탁자로서 **개인정보 보호법 제26조** 등에 따른 안전조치 의무를 이행한다. ② 목적 외 이용·제3자 제공·재위탁 금지(재위탁은 갑 사전 서면 동의). ③ **시크릿·개인정보는 보안 채널로만 전달·보관, 계약 종료 시 즉시 파기·통지**. ④ 을의 위반에 따른 유출 손해는 을이 배상한다.

**제19조 (재위탁 제한)** ① 을은 갑의 사전 서면 동의 없이 과업의 전부/일부를 제3자에 재위탁하지 아니한다.

**제20조 (납기 지연 배상)** ① 을의 귀책으로 납기 지연 시 **지체상금(지연일수 × 계약금액 × [0.1]%)** 을 갑에게 지급한다(상한 계약금액의 **[10]%**, 갑 귀책 지연 제외).

**제21조 (PMS·개발교육)** ① 제2조 No.1·No.2는 SAFE-LINK와 별개 과업으로 **산출물·범위·검수기준을 [별첨2]에 명시**한다. 불요 시 본 계약에서 제외하고 계약금액을 조정한다.

**제22조 (우선순위)** 본 보완서가 본문과 상충하는 경우 본 보완서를 우선 적용한다.

## 3. 별첨1 — SAFE-LINK 과업범위 명세

대상: SAFE-LINK 안드로이드·iOS 출시용 앱 + 기존 코드 리뉴얼. 구현 기준: 갑 이관 패키지(`SAFE-LINK_VENDOR_HANDOFF`) + 웹앱(`safe-link-v2.vercel.app`).

**A. 공통 기능 (양 플랫폼)**
1. 인증: 관리자 이메일 로그인 / 근로자 이니셜+뒷4자리 빠른 로그인 / QR·NFC 진입 / 세션 유지·갱신 / 복수 현장 선택
2. TBM 브로드캐스팅: 관리자 발송 → 근로자 실시간 수신 + 알림 (다국어)
3. TBM 서명: 다국어 번역 표시 / 음성 청취 / 서명 입력·제출 / 확인 기록
4. **라이브 통역(핵심)**: 실시간 음성(STT)→번역→음성(TTS), 양방향, 다국어, VAD, 자막
5. 1:1 대화: 실시간 채팅, 음성·번역·발음, 온라인 상태
6. NFC/QR 출입: 스캔, 체크인/아웃, 지오펜스
7. 다국어: 16개국어 이상 UI·통번역
8. 알림: TBM·메시지 수신 알림(푸시/로컬)
9. 오프라인/네트워크 실패 처리

**B. 코드 리뉴얼(No.3)**: 기존 자산 재사용 전제 정리·개선, 백엔드 유지(제14조). 세부는 착수 협의로 확정하되 본 명세를 하한으로 한다.

**C. 비기능**: 백엔드 재사용 / 디자인(`DESIGN.md`) 준수 / 스토어 심사 통과 / 보안·개인정보(제18조).

**D. 인수 체크리스트 (각 항목 실기기 동작 확인)**
- [ ] 관리자·근로자 로그인 (Android/iOS)
- [ ] TBM 발송 → 타 기기 실시간 수신·알림
- [ ] TBM 다국어 번역 → 서명 제출·기록
- [ ] **라이브 통역 양방향(2대): 음성→번역→음성** (Android/iOS)
- [ ] 1:1 대화 음성·번역 송수신
- [ ] QR/NFC 출입(지오펜스)
- [ ] 다국어 16개국어 전환
- [ ] 알림 수신 / 오프라인 안내
- [ ] Play·App Store 심사 통과·게시
