# 모바일 스토어 자산 준비 목록

## 공통

```text
앱 이름: SQ Link
앱 아이콘 원본: 1024 x 1024 PNG, 투명도 없음
브랜드 색상: 서원건설 확인 필요
앱 설명/부제목/키워드: apps/mobile/store/ios/app-store-connect.template.md 기준
지원 이메일: 회사 제공 필요
개인정보처리방침 URL: 회사 제공 또는 서비스 도메인에 배포 필요
계정 삭제 URL: 서비스 도메인에 배포 필요
```

## iOS 스크린샷

App Store Connect는 기기 크기별 스크린샷을 요구한다. 최소 1장, 최대 10장까지 올릴 수 있으며 JPG/PNG를 사용하고 투명도는 없어야 한다.

우선 준비 권장:

```text
iPhone 6.9형 또는 최신 대형 iPhone 세로 스크린샷
iPhone 6.5형 세로 스크린샷
iPad 지원을 유지한다면 iPad 스크린샷
```

권장 장면:

```text
1. 로그인 화면
2. 관리자 현장 대시보드
3. TBM 목록/상세
4. 근로자 QR 입장
5. 서명/확인 화면
6. 채팅/번역 화면
```

## Android 스크린샷

```text
휴대전화 스크린샷 4장 이상 권장
앱 아이콘 512 x 512 PNG
Feature Graphic 1024 x 500 PNG/JPG
```
