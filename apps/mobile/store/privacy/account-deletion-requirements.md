# 계정 삭제 출시 요건

Apple은 계정 생성을 지원하는 앱이 앱 안에서 계정 삭제를 시작할 수 있어야 한다고 요구한다. 단순히 이메일 주소만 안내하는 방식은 심사 지연 또는 거절 위험이 있다.

## SQ Link에 필요한 최소 흐름

```text
1. 로그인한 사용자가 계정/설정 화면에서 계정 삭제 요청으로 진입
2. 삭제 대상 계정과 삭제 영향 안내
3. 본인 재확인
4. 삭제 요청 생성
5. 처리 예정 시간 안내
6. 완료 또는 반려 결과 통지
7. 감사 로그 기록
```

## 바로 자동 삭제하면 안 되는 데이터

```text
산업안전 운영 기록, TBM 확인 이력, 서명, 감사 로그는 법적/계약상 보관 필요성이 있을 수 있다.
따라서 실제 삭제 정책은 개인정보 담당자와 확인해야 한다.
```

## 구현 전 결정 필요

```text
삭제 방식: 즉시 삭제 / 비활성화 후 보관 기간 만료 삭제 / 운영자 승인 후 삭제
보관 대상: TBM 기록, 서명, 감사 로그, 채팅, 음성/번역 로그
사용자 안내 문구: 어떤 데이터가 삭제되고 어떤 데이터가 법적 이유로 보관되는지
처리 SLA: 예 7일 또는 30일
관리자 화면: 삭제 요청 목록, 승인/반려, 처리 로그
```

## 출시 차단 상태

```text
현재 상태: 계정 삭제 정책/화면/API 최종 구현 필요
계정 수령 후 바로 심사 제출하려면 이 항목은 배포 전 반드시 완료해야 한다.
```
