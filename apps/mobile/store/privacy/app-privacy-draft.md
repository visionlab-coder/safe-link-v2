# App Privacy 답변 초안

이 문서는 App Store Connect의 App Privacy 설문 답변을 준비하기 위한 초안이다. 실제 제출 전에는 서원건설, 법무/개인정보 담당자, 운영 정책 담당자가 확인해야 한다.

## 수집 가능성이 높은 데이터

```text
연락처 정보:
- 이름
- 이메일
- 전화번호

식별자:
- 사용자 ID
- 계정 ID
- 현장/조직 소속 ID

사용자 콘텐츠:
- 서명 이미지
- 채팅 메시지
- TBM 응답
- 첨부/증빙 이미지
- 음성 입력 또는 STT 처리 대상 오디오

사용 데이터:
- 앱 기능 사용 로그
- TBM 확인/서명/읽음 상태

진단:
- 장애 로그
- API 오류 로그
- 기기/브라우저/OS 정보 일부
```

## 사용 목적 초안

```text
앱 기능 제공:
- 로그인, 현장 접근, TBM 확인, 서명, 채팅, 번역, 알림

앱 기능 개선:
- 오류 분석, 사용성 개선, 장애 대응

보안/부정 사용 방지:
- 권한 검증, 감사 로그, 현장 데이터 격리, 세션 보호

법적/운영 기록:
- 산업안전 관련 확인 이력, 서명 이력, 감사 로그
```

## 추적 여부 초안

```text
광고 목적 추적: 사용하지 않는 것으로 가정
타사 광고 네트워크: 사용하지 않는 것으로 가정
AI/번역/STT/TTS vendor 전송: 기능 제공 목적의 처리로 분류, vendor/지역/보관 정책 확인 필요
```

## 회사 확인 필요

```text
1. 개인정보처리방침 최종 URL
2. 계정 삭제/보관/복구 정책
3. 서명 이미지와 TBM 기록 보관 기간
4. 음성/STT/TTS 원본 저장 여부
5. 번역 vendor로 전송되는 데이터 범위
6. 현장 근로자 개인정보 처리 위탁 여부
7. 로그에 IP/user agent를 얼마나 보관하는지
8. 해외 이전 또는 국외 처리 여부
```
